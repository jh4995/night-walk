## 🟢 지금 당장 가능 — 7개

| 우선 | 무엇 | 값 |
|---|---|---|
| **1** | **조합 `D1A1` 720p GPU 측정** | 🔴 배포 후보인데 아무도 안 쟀다. **상류 CPU 결론을 뒤집을 수 있다** |
| **2** | **I칸 — ④ 실물 오버레이** | 최초 범위 B·D·I 중 유일한 미완. 명세 확정됨 |
| **3** | **폰 출력을 상류 `metrics.py` 3축으로 채점** | **골든 이미지 없이 품질을 재는 유일한 길** |
| 4 | `bf`(bilateral) 이식·측정 | 1위 후보 `D1A1+bf`의 비용 관건 |
| 5 | ③ 추론 배관 (더미 모델) | `C10`이 팀장·팀원2 공동. 모델 도착 시 대기 0 |
| 6 | `ts`(플리커 억제) 이식·측정 | 새 후보 `D1A1+bf+ts` 구성요소. ⚠️ **시간축 arm이라 프레임 간 상태를 갖는다** — 상류 파라미터를 그대로 옮기는 것은 되지만 **§B-4(리셋 조건·수렴 시간)는 여전히 ☐**라 지어내지 말 것. 수렴 구간을 warmup에서 어떻게 다룰지도 함께 정해야 한다 |
| 7 | `gamma_only` 지속 런 재측정 | 작은 빚 (STATUS 이슈 7) |

**1·2·3의 성격이 다르다** — 1은 **팀 결정을 바꾸는** 측정, 2는 **범위를 닫는** 측정, 3은 **막힌 것을 우회하는** 시도.

## 단계별

### 0 — 기반 ✅

문서 체계 · 계약서 · 측정 하네스(스키마 v3 · 승격 파이프라인 · 세션 오케스트레이터) ·
앱 뼈대(CameraX → GL 3패스, arm 6개) · GPU 구간 계측 · **A·B·D칸 실측**

### 1 — ② 저조도 (표시 경로)

| | 무엇 |
|---|---|
| ✅ | 단품 3종(D1·A1·A2) GPU 이식 + OpenCV 수치 대조 |
| ✅ | 단품 3종 D칸 실측 · 노이즈 바닥 · 발열 드리프트 없음 |
| 🟢 | **조합 `D1A1` 측정** · `bf` · `ts` · **`metrics.py` 3축 채점** · `gamma_only` 재측정 |
| ⏸ | **② 최종 선택** ← 🔴 **§B-6 골든 이미지** (팀장) |
| ⏸ | `A3` arm ← §B-4 계약값 (리셋 조건·수렴 시간) |

### 2 — ③ 위험 탐지

| | 무엇 |
|---|---|
| ✅👤 | YOLO11n `C4b` 학습 — 실야간 성능 확보 |
| 🟢 | **추론 배관 (더미/사전학습 모델)** — ORT 경로 뚫기 |
| ⏸👤 | **`C2` 자체 야간 촬영** ← 🔴 촬영 규약·초상권 (팀원3). **상류 크리티컬 패스** |
| ⏸👤 | 보행 시점 재검증 `C5` (대시캠 한계) ← `C2` |
| ⏸ | ONNX export · 실모델 이식 ← **해상도 · opset · NMS** (팀원1) |
| ⏸ | **E·F·G칸 실측** ← 모델 수령 |

### 3 — ④ 선택적 강조

| | 무엇 |
|---|---|
| ✅👤 | 명세 + PC 구현 (`emphasize.py`) — 이중 스트로크·비채움·노랑/시안·빨강 금지·깜빡임 금지 |

| | 무엇 |
