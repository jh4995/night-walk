- **3패스 렌더 골격 + arm** — `passthrough` / `blit_2pass` / `gamma_only`.
  ② 셰이더가 꽂힐 자리(패스2)가 비어 있다.
- **GPU timer query 동작 확인** — `GL_TIME_ELAPSED_EXT`(0x88BF)를 코어 `glBeginQuery`로.
  A34에서 **disjoint 0 / unresolved 0 / zero 0**. `stage_b_ms` · `stage_d_ms` · `gpu_present_ms`가 CSV로 나온다.
